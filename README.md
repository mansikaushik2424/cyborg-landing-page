# Cyborg-Themed Landing Page // Techfest IIT Bombay CA Task

A responsive, high-performance web interface designed with a futuristic cybernetic HUD theme. Built using HTML5, CSS3, and modern JavaScript.

## 🌟 Key Features
- **Cyberpunk / HUD Visual Design**: Neon color accents (`#00f0ff`, `#ff007f`), dark glassmorphism, and subtle scanline animations.
- **Responsive Layout**: Designed to adapt seamlessly across mobile, tablet, and desktop viewports.
- **Interactive UI**: Animated statistical counters triggered via Intersection Observer, dynamic form feedback, and glowing micro-interactions.
- **Clean Structure**: Pure, dependency-free vanilla code for ultra-fast loading speed.
